    Nexus Console

    Nexus replaces the proprietary spectrometer of an MRI system by two commercial PCIe measurement cards from Spectrum Instrumentation, an arbitrary waveform generator (transmit) and a digitizer (receive), operated by an open-source Python software. Pulse sequences are defined in the open Pulseq format using PyPulseq and unrolled directly into RF and gradient waveforms, which are streamed to the transmit card without a vendor-specific sequence compiler. Received signals are demodulated, phase-corrected and decimated on the host and exported in the ISMRMRD format for reconstruction with any compatible framework. The console was developed and validated on a 50 mT low-field MRI system. It is not tied to a specific field strength or hardware setup: amplifiers, coils and system limits are described in a configuration file.

    Nexus Console or Nexus CLI?

    This documentation is aimed at developers and researchers who want to build on the console software itself, e.g. to develop new sequences, acquisition workflows or hardware integrations. Using the nexus-console repository alone requires a custom set of experiments or a runner script that handles all tasks around the acquisition, such as loading a sequence, setting the acquisition parameter and saving the data.

    If you only want to execute sequences and experiments, use the Nexus CLI instead. It runs Pulseq .seq files and protocols, exports the data as ISMRMRD, manages the acquisition parameter and provides basic calibrations, without writing Python.
