    Device configuration

    The device configuration describes the hardware of the MRI system: the measurement cards, the amplifiers, the gradient coils and the system limits. It is read from a YAML file when AcquisitionControl is created and remains fixed for the session. Parameters that change between measurements, such as the Larmor frequency, are passed with every sequence as AcquisitionParameter.

    flowchart LR
    Y(["YAML file"]) -->|"load_nexus_config"| N["NexusConfiguration"]
    N -->|"TxConfiguration"| T["TxCard"]
    N -->|"RxConfiguration"| R["RxCard"]
    N -->|"RxConfiguration"| P["RxProcessor"]
    N -->|"TxConfiguration,<br/>SystemLimits"| S["SequenceProvider"]
    N -->|"complete copy"| D["AcquisitionData"]

    The file is validated by NexusConfiguration and consists of the three sections described below. Unknown keys are ignored. A copy of the complete configuration is stored with every acquisition in meta["device_configuration"].

    TxConfiguration

    Transmit card (AWG), validated by TxConfiguration. channel_max_amplitude and channel_filter_type have four entries in the order [RF, gradient 1, gradient 2, gradient 3]; gradient_efficiency and gpa_gain have three entries, one per physical gradient channel.

    Attribute Unit Description
    device_path – Device path of the transmit card, e.g. /dev/spcm1
    sampling_rate MHz Sampling rate as integer; must equal RxConfiguration.sampling_rate, as the transmit card runs on the clock of the receive card (not checked by the software)
    channel_max_amplitude mV Output range per channel, 1–6000 mV into 50 Ω
    channel_filter_type – Output filter setting per channel, 0–3 (see card manual)
    rf_terminated_50ohm – true if the RF output is terminated into 50 Ω, false for high impedance (the output voltage doubles)
    gradients_terminated_50ohm – true if the gradient outputs are terminated into 50 Ω, false for high impedance (the output voltage doubles)
    gradient_efficiency T/m/A Gradient coil efficiency per physical gradient channel
    gpa_gain A/V Transconductance of the gradient power amplifier per physical gradient channel
    rf_to_mvolt mV/Hz Conversion of the PyPulseq RF amplitude to the output voltage
    rf_gain_lut_path – Optional, default none. Path to a lookup table for the linearization of the RF power amplifier (.npy, 65536 int16 values)

    RxConfiguration

    Receive card (digitizer), validated by RxConfiguration. All channel lists must have max_available_channels entries. As the receive card setup expects 8 entries per list, max_available_channels must currently be 8, also for cards with fewer channels.

    Attribute Unit Description
    device_path – Device path of the receive card, e.g. /dev/spcm0
    sampling_rate MHz Sampling rate as integer; the receive card is the clock master and provides this clock to the transmit card
    max_available_channels – Number of input channels of the card and length of all channel lists (8 for the M2p.5933-x4)
    channel_enable – Enable flag per channel; 1, 2, 4 or 8 channels must be enabled
    channel_max_amplitude mV Input range per channel: 200, 500, 1000, 2000, 5000 or 10000
    channel_terminated_50ohm – Input termination per channel, true for 50 Ω, false for high impedance
    num_processing_workers – Optional, default 1. Number of worker processes for the parallel processing of the receive data; 0 processes the data in the main process after the acquisition

    SystemLimits

    Limits of the MR system, validated by SystemLimits and passed to PyPulseq as Opts (AcquisitionControl.get_sequence_system()). max_grad, max_slew, block_duration_raster, grad_raster_time and adc_raster_time must be positive, all other values must not be negative. Numbers in exponent notation need a decimal point, e.g. 20.e-6: YAML reads 20e-6 as a string, which the model rejects.

    Attribute Unit Description
    max_grad Hz/m Maximum gradient amplitude
    max_slew Hz/m/s Maximum gradient slew rate
    rf_dead_time s Dead time before an RF pulse; the RF unblanking signal is set this time before the pulse
    rf_ringdown_time s Ring-down time after an RF pulse
    adc_dead_time s Dead time around an ADC event; the ADC gate is extended by this time on both sides
    block_duration_raster s Raster time of block durations
    rf_raster_time s Raster time of RF waveforms
    grad_raster_time s Raster time of gradient waveforms
    adc_raster_time s Raster time of ADC dwell times
    B0 T Optional, default 0.05. Static magnetic field strength

    Example

    The example configuration of the repository must be adapted to the target system.

    examples/example_device_config.yaml
    # ========================================
# Configuration file for the Nexus-console
# ========================================

# NOTE: This is just an example, parameters need to be adjusted for individual system

# >> TX DEVICE: M2p.6546-x4 -> /dev/spcm1 (AWG)
# Total number of (analog) transmit channels: 4
TxConfiguration:
  # Could be extended to a list
  device_path: "/dev/spcm1"
  # Number of channels
  max_available_channels: 4
  # Device sampling rate in MHz
  sampling_rate: 20
  # Max. output amplitude per channel in mV
  channel_max_amplitude: [200, 6000, 6000, 6000]
  # Filter configuration of each transmit channel
  channel_filter_type: [0, 2, 2, 2]
  # Configure if RF/gradients are terminated into 50 ohm impedance (true == 50 ohm)
  rf_terminated_50ohm: True
  gradients_terminated_50ohm: False
  # Calculate grad_to_volt per gradient channel:
  # Gradient efficiency in T/m/A
  gradient_efficiency: [0.37e-3, 0.451e-3, 0.4e-3]
  # Gradient power amplifier in A/V
  gpa_gain: [7.10, 7.10, 7.10]
  # Scales RF in Hz (pulseq) to mV
  rf_to_mvolt: 5.e-3
  # rf_gain_lut_path: "/path/to/lut.npy"


# >> RX DEVICE: M2p.5933-x4 -> /dev/spcm0 (Digitizer)
# Total number of receive channels: 8
RxConfiguration:
  # Could be extended to a list
  device_path: "/dev/spcm0"
  # Number of channels
  max_available_channels: 8
  # Device sampling rate in MHz
  sampling_rate: 20
  # Enable the receive channels
  channel_enable: [1, 0, 0, 0, 0, 0, 0, 0]
  # Set the max. amplitude per channel in mV, list length must at least match the number of enabled channels
  channel_max_amplitude: [200, 200, 200, 200, 1000, 1000, 1000, 1000]
  # Configure which channels are terminated into 50 ohm impedance (true == 50 ohm), list length must at least match the number of enabled channels
  channel_terminated_50ohm: [True, True, True, True, False, False, False, False]

SystemLimits:
  # Maximum gradient amplitude in Hz/m (PyPulseq system stores this unit)
  max_grad: 1703040.0 # equals 40 mT/m
  # Maximum slew rate in Hz/m/s (PyPulseq system stores this unit)
  max_slew: 2128800000.0 # equals 100 T/m/s
  # Dead time at the beginning of RF event in s, covered by rf_delay
  rf_dead_time: 20.e-6
  # Time delay at the end of an RF event in s
  rf_ringdown_time: 30.e-6
  # Time delay at the beginning of an ADC event in s
  adc_dead_time: 0.
  # Raster time for block durations
  block_duration_raster: 1.e-6
  # Raster time for RF pulses.
  rf_raster_time: 1.e-6
  # Raster time for gradient waveforms.
  grad_raster_time: 1.e-6
  # Raster time for ADC readout.
  adc_raster_time: 1.e-6
