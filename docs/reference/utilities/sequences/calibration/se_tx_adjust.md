# Spin-Echo Transmit Calibration

`se_tx_adjust` constructs a calibration sequence for determining the transmit (B1) gain using spin-echo signals at varying RF pulse durations. The spin-echo is more robust than the FID for B1 calibration in inhomogeneous fields, as it refocuses off-resonance dephasing.
