# T2 Relaxation

`t2_relaxation` constructs a multi-TE spin-echo sequence for quantitative T2 mapping. Each phase-encoding step corresponds to one echo time value, sampled uniformly between the specified minimum and maximum TE. See the [T2 relaxation example](../../../../examples/t2_measurement.md) for a complete usage demonstration.
